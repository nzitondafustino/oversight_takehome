Input / configuration / evidence errors raise. Inference failures stay explicit on lines. Missing required replay returns no partial batch.

Backend-independent evidence

Jev keeps native probabilities; LLM confidence is a coarse self-estimate. Shared finalization preserves names and conflicts without inferring recipient type from a name.

Policy completeness

All checks use the same uncertainty view. Incomplete context leaves affected rules open. disposition and decided are separate: a flagged receipt may remain undecided.

Execution and verification

Live, replay, or deterministic mode. Replay creates no provider client. Full typed exports retain details; brief exports omit some evidence. Tests use replay or fake providers.
